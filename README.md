# 🤖 Bot Discord — Anti-Raid | Anti-Spam | Anti-Nuke | Hosting

Bot completo de proteção para servidores Discord.

## Funcionalidades
- 🛡️ Anti-Raid — detecta entradas em massa
- 🔇 Anti-Spam — detecta mensagens repetidas e menções em excesso
- 💣 Anti-Nuke — detecta deleções em massa de canais, cargos e bans
- 🤖 Hosting de Bots — hospede outros bots com sistema de chaves

## Comandos Slash
- `/antiraid` — configurar proteção anti-raid
- `/antispam` — configurar proteção anti-spam
- `/antinuke` — configurar proteção anti-nuke
- `/hostbot` — gerenciar bots hospedados e chaves

## Instalação
```bash
npm install
npm run build
npm start
```

## Variáveis de Ambiente
```
DISCORD_TOKEN=seu_token_aqui
```
